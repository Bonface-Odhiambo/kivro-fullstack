BACKFILL EXISTING ADDRESSES (REQUIRED)
====================================================================

New addresses will automatically get share tokens, but EXISTING 
addresses need to be backfilled.

METHOD 1: SQL MIGRATION (RECOMMENDED - FASTEST)
--------------------------------------
1. Open Supabase SQL Editor or your database client

2. Run the migration file:
   supabase/migrations/20251022120000_backfill_share_tokens.sql

3. The migration will:
   - Create generate_share_token() SQL function
   - Generate unique tokens for all existing addresses
   - Add unique constraint and index
   - Show progress in NOTICE messages

4. Check output for confirmation

WHAT IT DOES:
- Generates unique base64url tokens (27 chars)
- Only updates addresses without share_token
- Shows progress every 10 addresses
- Adds database index for performance
- Ensures all tokens are unique


METHOD 2: NODE.JS SCRIPT (IF BACKEND CONFIGURED)
--------------------------------------
1. Ensure .env file has Supabase credentials:
   SUPABASE_URL=your_url
   SUPABASE_ANON_KEY=your_key

2. Run:
   cd backend
   node scripts/backfill-share-tokens.js

3. Watch console output for progress

====================================================================
SHARE TOKEN FORMAT
====================================================================

- 27-character base64url string
- Example: T9JvoDlAc47wVMbVcfe4VKdhlWysKuh
- URL-safe (no +, /, or = characters)
- Unique across all addresses
- Generated from 20 random bytes

SHARE URL STRUCTURE:
https://kivro.africa/kv/{share_token}

BACKEND ENDPOINT:
GET /api/addresses/public/:shareToken

VERIFICATION QUERIES
====================================================================

Check how many addresses have share tokens:

SELECT 
  COUNT(*) FILTER (WHERE share_token IS NOT NULL) as with_token,
  COUNT(*) FILTER (WHERE share_token IS NULL) as without_token,
  COUNT(*) as total
FROM kivro_addresses;

View sample share URLs:

SELECT 
  kivro_code,
  display_address,
  'https://kivro.africa/kv/' || share_token as share_url
FROM kivro_addresses
WHERE share_token IS NOT NULL
LIMIT 5;

====================================================================
TROUBLESHOOTING
====================================================================

ISSUE: Share URL shows "Address Not Found"
FIX: 
  1. Check address has share_token in database
  2. Verify address is_active = true
  3. Ensure address has latitude/longitude
  4. Run backfill migration if not done yet

ISSUE: Map doesn't show
FIX:
  1. Verify address has valid latitude/longitude values
  2. Check browser console for errors
  3. Ensure coordinates are reasonable (-90 to 90, -180 to 180)

ISSUE: Share URL is null/undefined
FIX:
  1. For OLD addresses: Run backfill migration
  2. For NEW addresses: Check backend is updated
  3. Verify generateShareToken() is being called

ISSUE: "Connection Refused" on share link
FIX:
  1. Ensure backend server is running (port 3001)
  2. Check VITE_API_URL in frontend .env
  3. Verify route exists: GET /api/addresses/public/:shareToken
