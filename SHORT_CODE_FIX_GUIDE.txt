====================================================================
SHORT CODE (PIN) GENERATION FIX
====================================================================

This fix ensures all KIVRO addresses have a unique short code (PIN)
that can be used for e-commerce checkout and easy sharing.

====================================================================
WHAT WAS THE PROBLEM
====================================================================

ISSUE: Addresses were being created without short_code values
ERROR: "Resolving KIVRO PIN: null" when copying PIN link
RESULT: PIN link feature didn't work for addresses without short_code

====================================================================
WHAT WAS FIXED
====================================================================

DATABASE (SQL Migration):
✅ Added short_code column to kivro_addresses table
✅ Created generate_short_code() function
   - Generates format: KV-ABC-123
   - Uses only non-confusing characters (no 0, O, 1, I)
   - Ensures uniqueness by checking existing codes
   
✅ Created auto-trigger for new addresses
   - Automatically generates short_code on INSERT
   - No backend code changes needed
   
✅ Backfilled all existing addresses
   - Every address now has a unique short_code
   - Format: KV-XXX-XXX (6 random chars)

FRONTEND (Defensive Coding):
✅ VerifyLocationModal now handles null short_code gracefully
✅ Shows "PIN generating..." message if short_code is null
✅ Only enables "Copy PIN Link" when short_code exists
✅ Prevents /pin/null URLs from being generated

====================================================================
SHORT CODE FORMAT
====================================================================

Pattern: KV-XXX-XXX
Example: KV-A2B-7K9

Characters Used:
- Letters: A-Z (excluding I, O for clarity)
- Numbers: 2-9 (excluding 0, 1 for clarity)
- Total: 32 possible characters per position
- Combinations: 32^6 = 1,073,741,824 unique codes

Why This Format:
✅ Human-friendly (easy to read and type)
✅ No confusing characters (0/O, 1/I/l)
✅ Short enough to remember
✅ Long enough to be unique
✅ Perfect for e-commerce checkout
✅ Easy to communicate over phone

  COUNT(*) FILTER (WHERE short_code IS NOT NULL AND short_code != '') as has_code,
  COUNT(*) FILTER (WHERE short_code IS NULL OR short_code = '') as no_code,
  COUNT(*) as total
FROM kivro_addresses;

-- View sample short codes
SELECT 
  kivro_code,
  short_code,
  display_address
FROM kivro_addresses
ORDER BY created_at DESC
LIMIT 10;

-- Test uniqueness
SELECT 
  short_code, 
  COUNT(*) as count
FROM kivro_addresses
WHERE short_code IS NOT NULL
GROUP BY short_code
HAVING COUNT(*) > 1;

Expected: No duplicate short codes
