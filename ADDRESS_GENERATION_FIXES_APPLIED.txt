WHAT3WORDS INTEGRATION:
-----------------------

The KIVRO Precision method now uses What3Words API:
- Format: three.word.address (e.g., filled.count.soup)
- Validates format before API call
- Converts to GPS coordinates automatically
- Shows nearest place and country
- Stores what3words address in database

Requirements:
- WHAT3WORDS_API_KEY must be set in backend/.env
- If not set, precision method will show error message
- API key available at: https://what3words.com/developers
