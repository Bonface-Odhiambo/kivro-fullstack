================================================================================
TROUBLESHOOTING
================================================================================

Problem: "User not found" error
Solution: Ensure principalresearcher138@gmail.com exists in auth.users
         Check spelling of email address

Problem: Duplicate key error on government_senders
Solution: The script uses ON CONFLICT DO NOTHING, so this shouldn't happen
         If it does, the senders already exist and messages will still insert

Problem: Messages not appearing in inbox
Solution: Check user_id matches between auth.users and user_inbox
         Run verification queries included in the migration

Problem: Senders not showing in "My Senders" tab
Solution: Ensure sender_id foreign key is properly set in user_inbox
         The relationship should be automatic via the sender_id column
