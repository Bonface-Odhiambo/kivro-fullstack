# KIVRO ADMIN PANEL DEPLOYMENT GUIDE
## Deploying to admin.kivro.africa

### Overview
This guide will help you deploy the KIVRO Admin Panel to a separate subdomain (admin.kivro.africa) while keeping the main app at kivro.africa.

---

## 🏗️ Architecture

**Main App:** kivro.africa (User Dashboard)
- Build: `npm run build`
- Output: `dist/`
- Config: `vercel.json`

**Admin Panel:** admin.kivro.africa (Admin Dashboard)
- Build: `npm run build:admin`
- Output: `admin-dist/`
- Config: `admin-vercel.json`

---

## 📋 Prerequisites

1. Vercel account (or any hosting provider)
2. Domain: kivro.africa configured in your hosting
3. Git repository with your code
4. Environment variables ready

---

## 🚀 Deployment Steps

### Option 1: Deploy via Vercel CLI (Recommended)

#### Step 1: Install Vercel CLI
```bash
npm install -g vercel
```

#### Step 2: Login to Vercel
```bash
vercel login
```

#### Step 3: Deploy Main App (kivro.africa)
```bash
# From project root
vercel --prod
```

When prompted:
- Set up and deploy: Yes
- Which scope: Your account
- Link to existing project: No (first time) or Yes (subsequent)
- Project name: kivro-main
- Directory: ./
- Override settings: No

#### Step 4: Deploy Admin Panel (admin.kivro.africa)
```bash
# Deploy admin panel as a separate project
vercel --prod --name kivro-admin --config admin-vercel.json
```

When prompted:
- Set up and deploy: Yes
- Which scope: Your account
- Link to existing project: No (first time) or Yes (subsequent)
- Project name: kivro-admin
- Directory: ./
- Override settings: No

---

### Option 2: Deploy via Vercel Dashboard

#### For Main App (kivro.africa):

1. **Go to Vercel Dashboard**
   - Visit: https://vercel.com/dashboard

2. **Import Project**
   - Click "Add New" → "Project"
   - Import your Git repository
   - Name: `kivro-main`

3. **Configure Build Settings**
   - Framework Preset: Vite
   - Build Command: `npm run build`
   - Output Directory: `dist`
   - Install Command: `npm install`

4. **Add Environment Variables**
   ```
   VITE_API_URL=https://api.kivro.africa
   VITE_SUPABASE_URL=https://dfcuyinwearuhlhrdssx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   WHAT3WORDS_API_KEY=6MVHYCBT
   ```

5. **Deploy**
   - Click "Deploy"
   - Wait for build to complete

6. **Configure Domain**
   - Go to Project Settings → Domains
   - Add domain: `kivro.africa`
   - Add domain: `www.kivro.africa` (optional)
   - Follow DNS configuration instructions

#### For Admin Panel (admin.kivro.africa):

1. **Import Project Again**
   - Click "Add New" → "Project"
   - Import the SAME Git repository
   - Name: `kivro-admin`

2. **Configure Build Settings**
   - Framework Preset: Vite
   - Build Command: `npm run build:admin`
   - Output Directory: `admin-dist`
   - Install Command: `npm install`
   - Root Directory: `./` (same as main)

3. **Add Environment Variables**
   ```
   VITE_API_URL=https://api.kivro.africa
   VITE_SUPABASE_URL=https://dfcuyinwearuhlhrdssx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   VITE_ADMIN_PORTAL=true
   VITE_APP_TITLE=Kivro Admin Portal
   ```

4. **Deploy**
   - Click "Deploy"
   - Wait for build to complete

5. **Configure Domain**
   - Go to Project Settings → Domains
   - Add domain: `admin.kivro.africa`
   - Follow DNS configuration instructions

## 🌐 DNS Configuration

Add these DNS records to your domain provider (e.g., Namecheap, GoDaddy, Cloudflare):

### For Main App (kivro.africa):
```
Type: A
Name: @
Value: 76.76.21.21 (Vercel IP)
TTL: Automatic

Type: CNAME
Name: www
Value: cname.vercel-dns.com
TTL: Automatic
```

### For Admin Panel (admin.kivro.africa):
```
Type: CNAME
Name: admin
Value: cname.vercel-dns.com
TTL: Automatic
```

**Note:** Vercel will provide specific DNS values in the dashboard.

## 🔧 Backend API Deployment

Your backend API should be deployed separately to `api.kivro.africa`:

### Deploy Backend to Vercel:

1. **Create separate project for backend**

   - Root Directory: `backend`
   - Build Command: (none for Node.js)
   - Output Directory: (none)

2. **Add Environment Variables**

   SUPABASE_URL=https://dfcuyinwearuhlhrdssx.supabase.co

   EMAIL_PORT=587
   EMAIL_USER=noreply@kivro.africa
   EMAIL_PASSWORD=Z@y@n6339!
   EMAIL_FROM=noreply@kivro.africa

3. **Configure Domain**

## 🐛 Troubleshooting

### Issue: "404 Not Found" on admin.kivro.africa
**Solution:**
- Check build command is `npm run build:admin`
- Check output directory is `admin-dist`
- Verify `admin-vercel.json` is being used

### Issue: Admin panel shows user dashboard
**Solution:**
- Check `VITE_ADMIN_PORTAL=true` is set in environment variables
- Clear browser cache
- Rebuild and redeploy

### Issue: API calls failing
**Solution:**
- Check `VITE_API_URL` points to correct backend
- Verify CORS settings in backend
- Check API is deployed and running

### Issue: DNS not resolving
**Solution:**
- Wait 24-48 hours for DNS propagation
- Use `nslookup admin.kivro.africa` to check DNS
- Verify DNS records in domain provider

### Issue: SSL certificate error
**Solution:**
- Wait for Vercel to provision SSL (usually automatic)
- Check domain is verified in Vercel
- Try removing and re-adding domain

## 🔄 Continuous Deployment

### Automatic Deployments:
Vercel automatically deploys when you push to Git:

1. **Production Branch:** `main` or `master`
   - Pushes to this branch deploy to production
   - URL: admin.kivro.africa

2. **Preview Branches:** Any other branch
   - Creates preview deployment
   - URL: kivro-admin-git-branch-name.vercel.app

### Manual Deployments:
```bash
# Deploy specific branch
vercel --prod --branch feature-branch

# Rollback to previous deployment
vercel rollback
```
