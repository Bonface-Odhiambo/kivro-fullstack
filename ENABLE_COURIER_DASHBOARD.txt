# Enable Courier Dashboard - Quick Fix Guide

## Problem:
The "Courier Dashboard" tab is not showing in the navigation menu even though you registered as a courier.

## Cause:
The `user_type` field in your profile is not set to 'courier' in the database.

## Solution:

### Step 1: Check Your User Type

1. Open Supabase Dashboard: https://supabase.com/dashboard
2. Go to your KIVRO project
3. Click "SQL Editor" in the left sidebar
4. Run this query (replace the email with yours):

```sql
SELECT 
    p.user_id,
    u.email,
    p.display_name,
    p.user_type,
    p.phone_number
FROM public.profiles p
JOIN auth.users u ON u.id = p.user_id
WHERE u.email = 'graciaariel777@gmail.com';
```

### Step 2: Set User Type to Courier

If `user_type` is NULL or not 'courier', run this:

```sql
-- Update profile table
UPDATE public.profiles
SET user_type = 'courier'
WHERE user_id IN (
    SELECT id FROM auth.users WHERE email = 'graciaariel777@gmail.com'
);

-- Update auth metadata
UPDATE auth.users
SET raw_user_meta_data = raw_user_meta_data || '{"user_type": "courier"}'::jsonb
WHERE email = 'graciaariel777@gmail.com';
```

### Step 3: Verify the Update

Run the check query again:

```sql
SELECT 
    p.user_id,
    u.email,
    p.display_name,
    p.user_type
FROM public.profiles p
JOIN auth.users u ON u.id = p.user_id
WHERE u.email = 'graciaariel777@gmail.com';
```

You should see: `user_type = 'courier'`

### Step 4: Refresh Dashboard

1. Go back to your KIVRO dashboard
2. **Hard refresh** the page (Ctrl + Shift + R or Cmd + Shift + R)
3. You should now see the "Courier Dashboard" tab in the menu!

---

## Alternative: Check Browser Console

1. Open your dashboard
2. Press F12 to open Developer Tools
3. Go to "Console" tab
4. Look for a log message: "User profile loaded:"
5. Check what `user_type` value is showing
6. If it's not 'courier', follow steps above

If the tab still doesn't show:
1. Check browser console for errors
2. Verify the SQL update ran successfully
3. Try logging out and logging back in
4. Clear browser cache

The Courier Dashboard will show:
- Welcome banner
- Delivery stats (Total, Success Rate, Rating)
- How to use KIVRO guide
